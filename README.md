# Credit Card Dataset Analysis

This project focuses on analyzing a credit card dataset to understand patterns and insights from transaction data.  
The dataset is commonly used for learning data analysis and machine learning concepts such as fraud detection.

## Dataset
- File: `creditcard.csv`
- Contains transaction records made by credit cards
- Includes numerical features and a class label indicating fraud or non-fraud transactions

## Objectives
- Explore and understand the structure of the dataset
- Perform basic data analysis
- Identify patterns in transaction behavior
- Serve as a foundation for machine learning models
